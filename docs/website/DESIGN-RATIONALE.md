# Website design rationale — RLY-WEB-M-001

Visual reference: the Founder-provided Arena Beacon concept. This site is a new isolated static implementation, not a copy of its invented content.

## Retained
- Cream surface, near-black self-hosting section, rust accent, thin rules, compact technical navigation, generous editorial spacing.
- Large typographic hero with a paired internal incident/public status demonstration.
- Single-clock workflow, practical terminal quick start, open-source closing section.

## Changed deliberately
- Restored Relay identity and removed invented badges, integration marquees, statistics, testimonials, changelog and fake live console controls.
- Serif display emphasis appears in the hero, product heading and self-hosting heading only. Most headings are plain sans.
- Small uppercase monospace is reserved for section navigation and actual UI metadata; no decorative nine-card taxonomy.
- Three differently weighted product areas replace repeated symmetric card grids. Borders group UI evidence, timeline, resources and terminal—not every paragraph.
- Demo timestamps and company name are clearly identified as illustrative; no mockup suggests a real customer, active service or usage figure.

## System
System sans and Georgia display avoid a font network request. Max-width and responsive gutters keep the hero intentional. At tablet the paired demo remains two columns; at phone it becomes a vertically stacked view. Terminal code scrolls horizontally if necessary. Navigation wraps into a dedicated mobile row rather than collapsing to inaccessible hidden links.

Semantic landmarks, heading sequence, skip link, visible focus, text labels alongside status colors, and reduced-motion handling are included. No animation or JavaScript is required for the public page.
