03 / What ships today

Built for the actual work.

01

From alert to incident

Durable generic alert intake, canonical incidents, severity, affected systems and timelines. Alert intake does not automatically declare an incident.

02

Communicate with intent

Internal notes stay within the operator workflow. Explicit public updates appear on public Status Pages. Discord webhook notifications are supported.

03

Own the infrastructure

PostgreSQL persistence, REST API, OpenAPI metadata and SSE refresh events. Deploy with Docker Compose and keep the data in your environment.

04 / Self-host Relay

Run it where
you run things.

Relay 0.1 ships with a Dockerfile and Docker Compose deployment backed by PostgreSQL. Start locally, inspect the code, and configure secrets before any non-local use.
